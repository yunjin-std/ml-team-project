# Validation Log - 나지라

## 프로젝트명
Uplift Modeling 기반 마케팅 타겟 최적화 시스템

## 담당 역할
UI 및 백엔드 설계 / Streamlit 기반 대시보드 구현

## 검증 목적
모델 결과 CSV 파일이 대시보드에 정상적으로 업로드되고, 마케팅 의사결정에 필요한 정보가 올바르게 표시되는지 확인하기 위해 검증을 진행했습니다.

## 검증 내용

### 1. CSV 업로드 기능 확인
최종 모델 결과 CSV 파일을 대시보드에 업로드했습니다.  
파일 업로드 및 드래그 앤 드롭 방식으로 CSV가 정상적으로 불러와지는지 확인했습니다.

### 2. 필수 컬럼 확인
대시보드 실행에 필요한 컬럼이 CSV 파일에 포함되어 있는지 확인했습니다.

확인한 컬럼:
- customer_id
- uplift_score
- segment
- recommendation
- top_factor_1
- top_factor_2
- top_factor_3

### 3. KPI 요약 확인
CSV 업로드 후 전체 고객 수, 추천 고객 수, 추천 비율, 평균 마케팅 효과 점수가 정상적으로 표시되는지 확인했습니다.

### 4. 고객 결과 탭 확인
고객별 마케팅 효과 점수와 마케팅 추천 결과가 표 형태로 정상 출력되는지 확인했습니다.  
추천 고객 리스트가 따로 표시되는지도 확인했습니다.

### 5. 타겟팅 분석 탭 확인
고객 세그먼트 분포가 정상적으로 표시되는지 확인했습니다.  
또한 Top 10%, 15%, 20%, 30% 타겟팅 비교 결과가 정상적으로 나타나는지 확인했습니다.

### 6. 비용 시뮬레이션 탭 확인
이메일 발송 단가와 예상 수익 값을 입력했을 때 예상 매출, 예상 비용, 예상 순이익이 정상적으로 계산되는지 확인했습니다.

### 7. SHAP 설명 탭 확인
고객별로 추천 결과에 영향을 준 주요 요인 Top 3가 정상적으로 표시되는지 확인했습니다.  
또한 기술적인 변수명이 구매 이력, 최근 구매 시점, 고객 구매 패턴 등 쉬운 한국어 표현으로 표시되는지 확인했습니다.

### 8. 시연 영상 확인
최종 대시보드 기능을 기반으로 시연 영상을 촬영했습니다.  
영상에서 CSV 업로드, 고객 결과, 타겟팅 분석, 비용 시뮬레이션, SHAP 설명 기능이 모두 보이는지 확인했습니다.

## 검증 결과
최종 CSV 파일을 사용했을 때 대시보드는 오류 없이 정상적으로 작동했습니다.  
주요 기능들이 모두 확인되었으며, 발표 시연에 사용할 수 있는 상태로 준비되었습니다.
