## 검증 사례 1 — RF AUC 이상값 수정

**AI가 제안한 내용:**
Random Forest 모델 코드를 그대로 학습시키도록 제안

**틀렸던 부분:**
실제 돌려보니 RF AUC가 0.4654로 랜덤(0.5)보다 낮게 나옴

**수정한 내용:**
conversion이 0.91%밖에 없는 심각한 클래스 불균형 문제임을 확인하고,
언더샘플링(10:1 비율)으로 훈련 데이터 균형 맞춘 후 재학습

**왜 수정했는지:**
AUC 0.5 이하는 랜덤보다 못한 모델이므로 그대로 사용 불가.
클래스 불균형이 원인임을 파악하고 언더샘플링으로 해결 → AUC 0.5225로 개선

## 검증 사례 2 — X-Learner 과적합 판단

**AI가 제안한 내용:**
AUUC 기준으로 X-Learner(19.13)가 가장 높으므로 성능 우수하다고 설명

**틀렸던 부분:**
AUUC만 보면 X-Learner가 1위이지만,
실제로 Uplift > 0 비율이 86.1%로 전체 고객의 86%를 효과 있다고 예측 → 비현실적

**수정한 내용:**
AUUC 단독 기준이 아닌 Uplift > 0 비율과 함께 종합 판단하여
X-Learner 과적합으로 제외, T-Learner(AUUC 17.25, Uplift>0 21.2%) 채택

**왜 수정했는지:**
단일 지표만으로 모델을 판단하면 과적합 모델을 채택할 위험이 있음.
실제 마케팅 맥락에서 86%를 타겟하는 건 비현실적이므로
복수 지표를 종합해서 판단하는 것이 타당함

## 검증 사례 3 — Womens 고객 treatment 처리 문제

**AI가 제안한 내용:**
전체 64,000명 CSV 생성 시 Mens T-Learner 하나로 전체 예측하도록 코드 제공

**틀렸던 부분:**
Mens T-Learner는 Mens E-Mail vs No E-Mail 기준으로 학습했기 때문에
Womens E-Mail 고객을 Control처럼 처리하게 되어 부정확한 uplift 예측

**수정한 내용:**
Womens용 T-Learner를 별도로 학습한 후,
각 고객의 segment에 맞는 모델로 예측하도록 수정
(Mens → Mens T-Learner, Womens → Womens T-Learner, No E-Mail → 두 모델 평균)

**왜 수정했는지:**
팀원(나지라)의 대시보드가 전체 64,000명 데이터를 사용하므로
Womens 고객도 정확하게 예측해야 대시보드 연동이 올바르게 작동함
