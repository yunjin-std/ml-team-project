# AI 사용 로그 - 나지라

## 프로젝트명
Uplift Modeling 기반 마케팅 타겟 최적화 시스템

## 담당 역할
UI 및 백엔드 설계 / Streamlit 기반 대시보드 구현

## 사용한 AI 도구
ChatGPT

## AI 사용 내용

### 1. 대시보드 구조 설계
대시보드에 어떤 기능을 넣어야 할지 정리하기 위해 AI를 활용했습니다.  
주요 기능은 CSV 업로드, KPI 요약, 고객별 결과 확인, 타겟팅 분석, 비용 시뮬레이션, SHAP 설명 탭으로 구성했습니다.

### 2. 코드 작성 및 오류 해결 보조
Streamlit 대시보드 코드를 작성하는 과정에서 AI를 참고했습니다.  
특히 CSV 파일 업로드 방식, 필요한 컬럼 확인, 고객 결과 테이블 표시, 추천 고객 리스트 출력, 탭 구조 구성 등에 활용했습니다.

### 3. CSV 컬럼 연결 문제 해결
모델 결과 CSV 파일과 대시보드 코드의 컬럼명이 맞지 않는 문제가 있어 AI의 도움을 받아 필요한 컬럼을 확인하고 수정했습니다.  
확인한 주요 컬럼은 customer_id, uplift_score, segment, recommendation, top_factor_1, top_factor_2, top_factor_3입니다.

### 4. 사용자 친화적인 표현 수정
발표 피드백을 반영하여 기술적인 표현을 더 쉽게 바꾸는 데 AI를 활용했습니다.  
예를 들어 “uplift score”를 “마케팅 효과 점수”처럼 비전공자도 이해하기 쉬운 표현으로 수정했습니다.

### 5. 발표 및 시연 준비
대시보드 시연 영상에서 설명할 순서와 발표 스크립트를 정리하는 데 AI를 활용했습니다.  
고객 결과, 타겟팅 분석, 비용 시뮬레이션, SHAP 설명 순서로 설명 흐름을 구성했습니다.

## 최종 활용 방식
AI는 코드 작성, 오류 해결, 설명 문구 개선, 발표 준비를 보조하는 도구로 사용했습니다.  
최종 대시보드 구현 내용과 발표 자료는 팀원들과 확인하며 수정했습니다.
